# ChainEquity — Enterprise Blockchain Project

ChainEquity explores blockchain-enabled equity and capital-raising workflows for small and medium-sized enterprises. The project combines enterprise requirements analysis, investor-facing communication, and decentralised system design.

## Focus areas

- Equity tokenisation and ownership records
- Transparent investment workflows
- SME onboarding and investor access
- Blockchain applications in financial services

The repository is a static presentation prototype created as part of a collaborative MSc enterprise-development project.
